# Introduction
This repo contains the software for a launcher of presents to the moon, part of the 2026 Christmas display on my [front garden railway](https://www.meades.org/railways/garden/garden.html).  This software runs on the hardware of the Halloween [spider launcher](https://github.com/RobMeades/spider_launcher).  For more details see here:

https://www.meades.org/misc/christmas_2026/christmas_2026.html#Presents_To_The_Moon
